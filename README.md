# New DSS

重新建立個人化 DSS（Decision Support System）的設計紀錄。

## 目的

New DSS 是個人交易的研究與決策輔助工具，不是買賣指令、投資建議或報酬保證。

它的核心用途有兩個：

1. 以技術面與籌碼面描述目前標的的條件與結構。
2. 從使用者自己的歷史交易資料萃取可研究的候選參數；所有變更必須先預覽並由使用者明確確認。

## 重建策略

不修補既有 DSSLab 的龐大程式。先建立可測試、可解釋的核心邏輯，再依序建立資料匯入、研究結果與即時判讀 UI。

詳細的已確認決策請見 [decisions.md](./decisions.md)，尚未定案的項目請見 [open-questions.md](./open-questions.md)。

## 範圍

- 使用者持有 ETF 與個股。
- ETF 偏長線操作；個股偏波段操作。
- ETF 與個股共用一套核心判讀邏輯，但採用不同參數 profile。
- v1 不以上市／上櫃作為技術規則分界。
